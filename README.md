# Vacaciones iPhone

Agenda visual para planificar vacaciones por días y horas, pensada para iPhone.

## Publicarla con GitHub Pages

1. Entra en Settings del repositorio.
2. Abre Pages.
3. En Source, elige Deploy from a branch.
4. En Branch, elige `main` y carpeta `/root`.
5. Guarda.
6. GitHub generará una URL parecida a `https://xavijb.github.io/vacaciones-iphone/`.

## Instalarla en iPhone

1. Abre la URL de GitHub Pages en Safari.
2. Pulsa compartir.
3. Elige Añadir a pantalla de inicio.
4. Confirma con Añadir.

La app guarda tus notas en el navegador del iPhone usando almacenamiento local.
